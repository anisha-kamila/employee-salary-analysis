# 📊 Employee Salary Analysis Dashboard

## 📌 Overview

An interactive Employee Salary Analysis Dashboard built using Microsoft Excel to analyze HR data and generate meaningful business insights. The project demonstrates Excel formulas, lookup functions, Pivot Tables, Pivot Charts, and dashboard creation.

---

## 📂 Dataset

- **Dataset:** IBM HR Analytics Employee Attrition & Performance
- **Source:** Kaggle
- **Purpose:** Educational and portfolio project

---

## 🛠 Tools & Skills

- Microsoft Excel
- Pivot Tables & Pivot Charts
- Slicers
- IF
- COUNTIF / COUNTIFS
- SUMIF / SUMIFS
- AVERAGEIF / AVERAGEIFS
- VLOOKUP
- XLOOKUP
- INDEX + MATCH

---

## 📊 Dashboard Features

- Employee Count by Department
- Average Monthly Salary
- Gender Distribution
- Attrition Analysis
- Average Experience
- Interactive Slicers
